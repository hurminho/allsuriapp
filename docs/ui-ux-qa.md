## 검수 방법에 대한 정직한 고지

이 문서의 판정은 두 가지 근거로 나뉩니다. 섞어 읽지 않도록 표기했습니다.

- **[자동]** — `flutter test` 로 4개 해상도·3개 글자 배율에서 실제 렌더링하고
  `RenderFlex overflow` 예외 발생 여부, 위젯 크기, 렌더된 텍스트를 단정한 항목.
  회귀가 생기면 CI 에서 바로 깨집니다.
- **[코드]** — 소스를 읽어 판단한 항목. 실제 기기·시뮬레이터에서 눈으로 확인한
  것이 아니므로, 아래 [수동 점검 필요](#5-실기기-수동-점검-필요-항목) 목록을
  릴리즈 전에 반드시 소화해야 합니다.

**실기기 및 시뮬레이터 육안 검수는 이번 작업에 포함되지 않았습니다.**

## 2. 발견된 이슈

### [P1] 사업자 프로필 — 저장 후 화면이 닫히지 않음

```
재현 절차
  1. 사업자 계정으로 로그인
  2. 내 정보 → 사업자 프로필 진입
  3. 필수 항목 입력 후 저장
  4. "환영합니다" 안내 다이얼로그에서 [시작하기] 탭

기대 결과
  다이얼로그가 닫히고 프로필 화면도 닫혀 대시보드로 돌아간다.

실제 결과
  다이얼로그만 닫히고 프로필 화면이 그대로 남는다.
  (릴리즈에서는 조용히, 디버그에서는 빨간 오류 화면)

원인 추정
  business_profile_screen.dart:233 이 go_router 의 context.pop() 을 호출.
  이 앱은 GoRouter 를 어디에도 설정하지 않아 라우터 조상을 찾지 못하고 예외 발생.
  pubspec 에 go_router 의존성만 있고 GoRouter(...) 인스턴스가 코드베이스에 없음.

수정 방향
  Navigator.of(context) 로 다이얼로그와 화면을 차례로 닫고,
  두 번째 pop 전에 canPop() 을 확인한다. 미사용 go_router import 제거.

테스트 여부
  수정 완료. 온보딩 직후 경로라 실기기 확인 권장 (§5 M-01)
```
